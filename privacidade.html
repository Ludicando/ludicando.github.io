Política de Privacidade

Última atualização: 16 de novembro de 2026.

Esta política vale para o site www.ludicando.com.br e para o aplicativo interno Ludicando Rclone particular, mantidos pela Ludicando, de Socorro-SP.

Site

O site é apenas informativo. Ele não tem formulários, não cria contas, não usa cookies de rastreamento nem ferramentas de publicidade ou de análise de visitas. O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso (como o endereço IP) conforme a política de privacidade do GitHub.

Os links para WhatsApp, Instagram e Facebook levam a serviços de terceiros, que têm políticas próprias.

Aplicativo Ludicando Rclone particular

É um aplicativo de uso interno, usado somente pela equipe da Ludicando para fazer cópias de segurança (backup) dos arquivos da própria Ludicando no Google Drive, com a ferramenta de software livre rclone.

  • Dados acessados: arquivos e pastas do Google Drive da conta da Ludicando que autorizar o acesso.
  • Uso: enviar, listar, conferir e baixar cópias de segurança. Nada além disso.
  • Armazenamento: o acesso é feito diretamente entre os computadores da Ludicando e o Google. Não existe servidor intermediário e os dados não são guardados por terceiros.
  • Compartilhamento: os dados não são vendidos, compartilhados nem usados para publicidade, nem para treinar modelos de inteligência artificial.
  • Revogação: o acesso pode ser retirado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Alunos e famílias

Dados de matrícula de alunos e responsáveis não passam por este site nem por este aplicativo. Eles são tratados apenas para a prestação das aulas, de acordo com a Lei Geral de Proteção de Dados (Lei 13.709/2018).
